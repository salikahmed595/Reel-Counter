Install steps
  1. Tap Download for Android and open the downloaded file.
  2. If asked, allow your browser to install unknown apps.
  3. Open the app, read the privacy screen and tap Agree.
  4. Turn on PAICONS Self-Development tracking in Accessibility settings.
  5. Android 13+: if you see “Restricted setting”, open App info → ⋮ → Allow restricted settings, then turn it on again.
